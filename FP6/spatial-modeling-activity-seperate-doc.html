Here are some solutions to the the above problem.

Solution 1: Simply remove the island.

If you are running a model where things cannot cross large bodies of water (i.e. feral swine cannot swim to distant islands), then removing the island is a simple solution to the problem.

# Removing island
joined_counties_WA_removed <- joined_counties_WA |> 
  filter(GEOID != "53055")

centroids <- st_centroid(st_geometry(joined_counties_WA_removed), of_largest_polygon = TRUE)

queen_nb_removed <- poly2nb(joined_counties_WA_removed, queen = TRUE)

gmoran <- moran.test(joined_counties_WA_removed$wheat, nb2listw(queen_nb_removed), alternative = "greater")

Solution 2: Running a different type of model.

Different types of models do not have the same types of restrictions as a saptial lag model, and have different ways in which they can include islands.

However, what might we not get from this type of model that we might from a spatial lag model?

Solution 3: Change the zero.policy value

The zero.policy argument determines if the is a weight assigned to areas with zero neighbors. Without assignment, the value is automatically NULL. If the value is set to TRUE, for objects with no neighbors, lists will be formed with zero-length vectors.

gmoran <- moran.test(joined_counties_WA$wheat, nb2listw(queen_nb, zero.policy = TRUE), alternative = "greater")
